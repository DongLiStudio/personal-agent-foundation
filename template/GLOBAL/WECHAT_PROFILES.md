# WeChat Profiles

本文件记录本机微信只读分析的非敏感逻辑身份路由。真实数据库路径与经校验的密钥目录由当前 Windows 用户的 DPAPI CurrentUser 加密保存在宿主凭据槽中，不进入 GLOBAL、Git、日志或报告。

## Profile 索引

当前未配置。首次连接时逐个发现候选，并由用户确认账号归属和逻辑 Profile 名称；不得按最近活跃或当前登录自动选择。

## 路由规则

- 不设置全局默认 Profile；每次发现、连接、查询、搜索、统计或总结都显式指定逻辑 Profile。
- 一个 Profile 只绑定一个宿主候选；同一逻辑身份换电脑后必须重新发现、确认和绑定。
- GLOBAL 只保存逻辑名称、非敏感主体描述、用途、项目路由和验证状态；不保存 wxid、数据库路径、密钥、聊天内容、候选指纹或 DPAPI 密文。
- 用户确认账号归属并绑定 Profile，即授予该 Profile 在本机的持续只读权限，直到删除 Profile。首次取钥和必要的密钥刷新仍必须由用户明确触发。
- 删除或重命名 Profile 前，先搜索项目引用；删除本机绑定会撤销持续只读授权并删除 DPAPI 凭据槽，但不得删除微信数据。

## 换机恢复

1. 从 GLOBAL 恢复并安装 `wechat-readonly-analyst`。
2. 在用户级安装副本运行离线安装和 `profile_manager.py self-test`。
3. 逐个运行 `discover` 并让用户确认候选；不得复制旧电脑的 DPAPI 槽。
4. 对每个 Profile 执行连接和一次性取钥，再用最多 3 条会话完成最小回读。
5. 只有可用性、离线密钥和回读都成功后，才标记为可用。
