# 邮箱 Profile 与租户路由

本文件记录由 GLOBAL 统一维护的邮箱逻辑身份与非敏感路由。只记录 Profile 名称、所属主体、邮箱地址、服务商、用途、认证类型和验证方式；不得记录密码、客户端授权码、OAuth token、恢复码、会话 Cookie 或本地密文内容。

## 治理规则

- 邮箱 Profile 的选择顺序：用户当前明确指定 → 项目条件化路由 → 项目默认邮箱 Profile → GLOBAL 默认邮箱 Profile。没有唯一结果时，在读取邮件前询问。
- 每次读取前后都核验实际邮箱地址和所属主体；不得因某个网页、客户端或 CLI 当前已登录而静默使用该邮箱。
- 默认只读。搜索、读取和下载附件不得自动标记已读、移动、加标签、删除、回复、转发或发送。
- 公司、客户和个人邮箱相互隔离。认证成功不代表允许跨主体搜索，也不代表允许发信或修改邮件状态。
- 密钥与动态状态由对应服务商 OAuth、系统安全存储或本机凭据槽维护，不进入 GLOBAL、项目、Git、聊天记录或普通命令参数。

当前未设置。普通项目不得使用隐式默认邮箱。

## 已核验邮箱 Profile

当前未配置。连接后使用服务商或协议回读的真实邮箱地址和主体登记，不由 Agent 自拟名称。

## 项目路由

当前未配置。项目只保存业务路由与允许检索的邮箱 Profile，不复制邮箱生命周期与认证流程。

## 换机恢复

- 从本文件恢复非敏感路由。
- OAuth 邮箱重新执行服务商授权；通用 IMAP 邮箱重新输入客户端授权码或应用专用密码。
- 本机加密凭据不随 GLOBAL 或基座迁移。
- 恢复后只执行邮箱身份回读和只读搜索验证，不自动下载、写入业务系统或发信。
