# 服务器详情模板与填写约定

用于创建或更新 GLOBAL/servers/<profile>.md。保留以下四个二级章节及服务表六列；可以增加有实际用途的子章节。尖括号内容必须替换为已确认事实或“待核验”，不留占位符。示例服务器只参考结构，不继承身份、权限或服务。

```markdown
# <profile>

本文件记录该服务器的非敏感连接事实、服务归属与操作边界。运行状态须在每次操作前实时核验；项目专属部署步骤由对应项目维护。

## 定位与连接

- 治理归属：<归属>
- 环境：<环境与用途>
- 地址：<地址>
- SSH 端口：<端口>
- 操作系统参考：<系统与架构，注明核验日期>
- 主机名：<主机名>
- SSH 别名：<profile>
- SSH 主体：<账号>
- 当前人工 SSH 身份：Bitwarden Agent；<实际接入方式与验收日期，无私钥文件>
- 客户端公钥指纹：<指纹>
- ED25519 主机指纹：<指纹；采用其他算法时据实修改标签>

提供连接命令、最小只读核验命令、known_hosts 路由及指纹变化时的停止规则。注明实际连接核验日期，不把登记完成等同认证成功。

## 权限与安全边界

记录真实权限范围、跨项目影响、凭据保存边界和需独立授权的操作。不把风险观察当作变更授权。

## 服务索引

| 服务 | 租户 / 项目 | 运行与部署入口 | 持久化边界 | 网络边界 | 默认操作边界 |
| --- | --- | --- | --- | --- | --- |
| <服务或待盘点> | <归属> | <入口> | <数据边界> | <监听或入口> | <授权范围> |

## 恢复说明

说明换机安装 Bitwarden、启用 Agent、重建公开路由与主机信任、确认服务依赖及独立验收；默认不导出私钥，文件身份例外记录授权与风险。记录未解决的恢复风险。运行快照加日期，过程日志留项目任务文档。
```

验收时核对四章、六列、索引链接、连接字段与证据一致；区分监听地址与公网可达、服务进程与 systemd 状态、备份文件存在与恢复成功。未盘点业务不得为填表扩大远程读取范围。

详情是现行状态索引，不是变更日志。保留最近核验日期及必要验收边界；删除已撤销人工指纹、过时快照和重复迁移流水。有效自动化身份、应急回退路径及未解决风险必须保留；详细过程通过项目记录或 Git 历史追溯，不在 GLOBAL 复制历史备份。
