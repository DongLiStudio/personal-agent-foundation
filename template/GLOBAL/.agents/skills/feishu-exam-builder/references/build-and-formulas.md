# 建表、命题与公式

## 数据结构按考试模式选择

| 模式 | 最小组成与关键身份 |
|---|---|
| 纯客观卷 | 考生试卷表＋评分/汇总表；系统创建人识别考生 |
| 客观＋实操/附加 | 试卷＋实操提交（必要时）＋评分汇总；同一真实用户跨阶段关联 |
| 评委/答辩/路演 | 试卷/任务表＋评委评分表，必要时独立汇总；显式“被评人”人员字段，系统创建人是评分人 |
| 带教/多岗位 | 任务/试卷＋按实际岗位/模块拆分的评分表＋汇总；显式角色，严格按该岗位分支 |

至少有试卷表和评分表，且每名考生在同一考试版本与有效答卷下必须有唯一成绩汇总。不要为满足两表形式复制答卷，或把记录得分列冒充独立评分表。单人模式的评分表可同时承载汇总；多人评委通常采用试卷、评分明细、成绩汇总三表。若选择不拆表，必须证明每考生唯一汇总可被独立读取和权限隔离，不能仅有多条评委明细而缺少最终汇总。

- 考生版身份优先取系统创建人，不增加手填姓名、手机号、身份证、批次等冗余输入。外部考生若不能以当前用户唯一识别，先解决身份合同，不自动开放匿名。
- 评委表使用单选人员字段作为被评对象，独立保存评分人、时间；平台支持时直接以人员作为主字段。隐藏无意义“评分记录”系统问题。隐藏失败必须报告，不能让用户随便填来通过验收。
- 评分汇总行的被评人可能由人员主字段明确指定，不一定等于该行创建人。按真实字段结构建立关联，禁止照搬“所有表都按创建人”。
- 既有最简两列成绩表可保留；待评/缺评/重复源检查可由受限管理视图或审计清单承载，不未经授权添加字段。
- Grid 优先“被评人/主字段 → 总分与状态 → 系统身份/时间 → 题目与评语”；Form 按实际作答逻辑排列，两个顺序独立维护。

## 题目与字段的一份事实源

每道题维护唯一 qid（跨模块有重复可用 `模块.qid` 内部键），题型、能力目标/难度、来源、完整题干、选项、正确答案或细化评分点、分值、必填、对应表/字段 ID 与表单页序。显示题号可简短，底层键不得歧义。

单选唯一正确；多选声明全对得分或用户确认的部分分；填空显式可接受答案集合及空白/大小写/标点规范。动态事实按考试提交时点的权威来源人工复核，不把今日答案强用于历史答卷。

选项同场景、同层级、长度接近，有真实相邻错误，不靠绝对词/无关选项泄题；单选正确位置近似平衡，避免重复题与纯记题号。量表每个维度有行为、场景、证据和各档锚点，禁止只写“态度好”“能力强”。实操严格用题目自己的评分点，不另套通用 0—10 分维度。

`manifest题号 ↔ field_id及列名/说明 ↔ Form问题 ↔ 评分公式引用` 必须全量一致。表单标题正确不证明底层列正确。改题不复用其他语义的槽位；有真实答卷时语义修改通常需新版本。

## 计分数学

模块折合分 = 模块原始得分 / 模块原始满分 × 模块最终贡献上限。总分 = 已确认模块折合分之和；附加分是单独模块，明确是否允许总分大于 100。所有量表子项满分之和等于题满分，题满分之和等于模块原始满分，模块贡献之和等于最终满分。

- 用十进制定点校验，通常只在最终展示舍入，避免每题提前截断。60 题等权可用“答对数 / 60 × 100”，不把每题粗略写成 1.67。
- 未提交、缺评分人、证据不可读、公式报错、分母为零、未知岗位均不等于真实 0。允许技术性 subtotal 缺源按 0 显示时，必须并列待评/缺源状态，不能输出最终成绩。
- 已提交但未作答可按明确评分规则计 0；材料不可访问先标待核，不任意判 0。实操完全空白与有效提交但权限不足分开处理。
- 评委按“考生＋考试版本＋模块＋角色＋评分人”去重；所有预期角色齐全才完成。主/副带教权重、多人平均/加权和人数来自合同，不能自动平均所有记录或把多个岗位相加。
- 每人每天一次是提交限制，不是重考政策。检测到同人同版本多答卷、重复评委、跨版本记录即报告并确认，不任意 `FIRST`、取最高或最新。

## 飞书公式实施

先阅读当前 `lark-base` 的 field-formula 与跨表引用文档；将正确数学表达转为当前平台支持语法，记录原文和平台规范化表达。禁止手拼内部 DSL 或将 SQL 语法视为公式。

跨表引用采用当前文档认可的可读表达，例如 `[来源表].FILTER(CurrentValue.[被评人]=[考生]).[分数字段]`，但字段、数组/人员比较和聚合方式必须在目标环境实际验证。示例不是可直接复制的完整公式。

- 单选应按真实存储的选项值/ID精确判定，不假定单元格只存 A/B/C/D。
- 多选按完整集合判断，顺序无关。不能用文本子串函数判断列表；曾出现集合函数写入成功但真实答卷仍计 0。可采用每个正确项必须含有、每个错误项必须不含有的逻辑，但具体函数仍查当前文档并测试。
- 填空使用已批准的等价词库，禁止无界模糊包含（例如短词误命中更长错误术语）。语义争议上报，不自行向词库补答案。
- 公式字段回读成功仅证明写入；必须让隔离测试记录触发计算，再读取实际结果，与独立评分逐项比较。不得用正式考生记录试填/覆盖。

## 写入事务与回归

写前保存受影响 schema、公式、表单、权限配置快照和记录数量；操作日志记录动作、返回 ID、前后状态。新建失败从已确认成功步骤续跑，不自动删表回滚。更新只触及 manifest 指定字段。

表单问题更新可能是**全量替换**而非 PATCH：先读回 title、description、required、option_display_mode、visible_rule 等全部属性，修改目标属性后完整提交。批量建题顺序可能不稳定，按当前支持的前置字段/排序能力修正；单题正序创建也要回读。

最终全量比较题目、Form、Grid、公式；检查其他岗位/版本公式及已有成绩未变。必要时短间隔、有上限地重新回读应对延迟，不能无限重试或以返回 success 宣称已生效。
