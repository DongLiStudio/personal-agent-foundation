# {{exam_name}}阅卷

执行前完整读取项目 AGENTS.md、README.md、STATUS.md，以及项目声明的上层入口；再完整读取本 Skill 的 [资源路由](references/routing.md)、[评分细则](references/rubric.md)、[报告模板](references/report-template.md)。

固定使用 `--profile {{profile}} --as user`，授权失效即停止并恢复正确身份，不回退其他主体或 bot。

1. 唯一定位考试版本、考生稳定身份与有效答卷，实时核验所有 field ID、列名和表单题目映射；错位或重复记录先报告。
2. 从答卷独立逐题计分并与平台公式比较，任何差异直接报告，禁止修改公式、默改分数或用人工分补差。
3. 按评分细则逐项访问所有实操/附加题链接和附件；登记证据、可访问性与评分点，未知代码不执行。无法访问保留待核，真实零分与缺证据区分。
4. 全量报告含每题完整题面/选项、作答、标准答案/评分点、分数、依据、所有证据与差异；机械核对各级合计。
5. 按考试版本＋考生稳定身份＋有效答卷记录查找唯一报告，更新原报告或在零匹配时创建。仅写 routing.md 当前白名单中明确归本 Skill 负责的字段；多评委模式按 routing.md 的人数、角色、权重和齐套条件汇总，不用 AI 分冒充人工评委，不覆盖他人的评分记录。不改答卷、题库、结构、公式、权限或自动化。
6. 独立回读成绩与报告，差异/待核未解决不得标最终完成；交付结果、边界与下一步，不替代录用、职级、薪酬等决定。

具体识别、分值、证据门槛、报告归档与允许写入以本版本 references 为准；不依赖历史会话或其他考试的隐含规则。
