# 微信只读分析与 Profile 管理

本 Skill 把“逻辑身份路由”和“本机敏感绑定”分开：GLOBAL 的 `WECHAT_PROFILES.md` 只记录非敏感 Profile；具体 `db_storage` 路径和经数据库页校验的密钥目录由当前 Windows 用户的 DPAPI 加密保存，换电脑后重新绑定并重新取钥。

## 固定边界

- 仅处理用户本人拥有或明确获授权访问的本机微信数据。
- 每次操作必须显式指定 `--profile`；不设默认 Profile，不按最近活跃账号自动猜测。
- 用户确认账号归属并绑定 Profile，即授予该 Profile 在本机的持续只读权限，包括对本机可用微信数据库内容进行查询和在当前 Agent/模型上下文中分析；后续具体查询请求无需重复授权，直到用户删除该 Profile。
- 首次取钥或密钥目录失效需要刷新时，才只读扫描当前微信进程内存；校验后的密钥目录立即用 Windows DPAPI CurrentUser 加密写入宿主凭据槽。日常查询直接使用该凭据槽，微信无需在线或登录。
- 不写微信进程，不注入、不附加调试器、不修改客户端或权限，不关闭安全软件。
- 不发送或修改消息，不调用原始 CLI 绕过包装器，不输出密钥、wxid、数据库路径或原始数据库。
- 不设置隐私条数上限。大量查询按稳定性分页处理，直到覆盖用户指定范围；输出形式按用户目标选择明细、统计、摘要或报告。
- 用户指定需要图片、语音、视频或附件时可直接读取本机可用内容，无需另行重复授权；必须如实说明工具当前支持的媒体类型和未覆盖项。

## 路由

- 安装、换机恢复、Profile 新增/删除：读取 [安装与 Profile 生命周期](references/setup-and-profiles.md)。
- 查询、搜索、统计或总结：读取 [查询与隐私门禁](references/query-and-privacy.md)。
- 生成 HTML 报告：先形成已脱敏 JSON，再读取 [报告结构](references/report-schema.md)。
- 兼容失败：读取 [Windows 兼容与故障处理](references/windows-compatibility.md)；HMAC 校验不通过就停止，不猜密钥、不降级安全门禁。

## 最终回报

说明实际 Profile、读取的本机时间范围和数量、密钥来源（DPAPI 缓存或本次刷新）、媒体覆盖、临时目录清理状态及未覆盖内容。只能说“全部本机可用记录”，不得宣称覆盖服务器端、已删除、已过期或尚未下载的消息。
