# 邮箱发票与账单归集

## 检索策略

从已确认的未核销支出生成窄查询，优先使用：订单号、发票号码、商户名称、准确金额和合理日期窗口。不得无范围下载整个邮箱。

建议顺序：

1. 读取项目未核销账目，确认报销人、日期、金额、商户和订单号。
2. 在项目允许的每个邮箱 Profile 中按订单号搜索；无结果时再按商户、金额和日期窗口组合搜索。
3. 只读取命中邮件的元数据和附件名；确认相关后才下载附件。
4. 计算文件 SHA-256，并以发票号码、金额、开票日期和哈希检查重复。
5. 验证购买方、销售方、票面金额、税务字段与项目主体；无法确认时标记待人工复核。
6. 邮箱附件只是来源材料。挂到账目、上传OA或标记已核销仍须使用项目财务/审批 Skill，并遵守其写入授权。

## 默认不执行

- 不自动标记已读、移动邮件、添加标签或删除邮件。
- 不把邮件正文中的账号、密码、2FA、恢复码或个人证件复制到项目记录。
- 不因发票金额覆盖支出就忽略支付凭证、唯一交易标识和重复报销检查。
- 不把一个主体的发票用于另一个主体，除非项目制度明确允许且用户确认。

## 输出清单

- 已匹配：账目记录、邮件 Profile、邮件UID/消息ID、附件名、发票号码、票面金额、哈希。
- 未匹配：账目记录、已搜索 Profile、查询条件、缺失金额。
- 冲突：重复发票、购买方不符、金额/日期异常、疑似红冲或附件不可解析。
