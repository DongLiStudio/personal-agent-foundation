# 服务器详情目录

本目录用于按 Profile 拆分记录跨项目或跨会话稳定复用的服务器详情。每台受管服务器使用一个 `servers/<profile>.md` 文件；`SERVER_PROFILES.md` 只保留非敏感索引和读取路由。

公开模板不预置真实服务器地址、账号、主机指纹、私钥路径、容器名、服务清单或部署拓扑。新增服务器时，先由用户确认用途、权限边界和可信指纹来源，再通过 `server-profile` Skill 登记。

建议文件命名：

```text
servers/<稳定逻辑 Profile>.md
```

建议详情结构：

```text
# 服务器 Profile：<稳定逻辑 Profile>

## 定位与连接

- 定位：<服务器用途>
- 治理归属：<用户、组织或项目>
- 环境：<生产、预发布或测试>
- SSH 别名：<本机 ssh config 中的稳定别名>
- SSH 主体：<最小权限账号>
- 主机指纹核验：<可信云控制台或既有已验证会话>

## 权限与安全边界

- 默认操作边界：<只读、可部署或需逐次授权>
- 凭据保存：私钥、密码、token 和票据不进入 GLOBAL 或项目 Git。
- 高影响操作：发布、重启、改网、改卷、改权限或读取 Secret 前必须再次确认。

## 服务索引

| 服务 | 租户 / 项目 | 部署入口 | 持久化边界 | 网络边界 | 默认操作 |
| --- | --- | --- | --- | --- | --- |
| <服务名> | <归属> | <目录或编排入口> | <卷/数据库/对象存储边界> | <端口/域名/内网边界> | <只读/需确认> |

## 恢复说明

- 换机后从安全渠道恢复本机身份文件。
- 重新核验主机指纹，不自动接受未知或变化的主机密钥。
- 先做身份、目标目录和服务状态的有界只读回读，再判断是否具备后续操作条件。
```
