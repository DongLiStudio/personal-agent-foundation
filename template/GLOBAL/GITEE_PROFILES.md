# Gitee CLI 账号与工具路由

本文件记录跨项目使用的 Gitee 非敏感身份和工具约定。只记录账号、用途、Host、CLI 路径、核验方法和项目路由；不得记录 PAT、密码、SSH 私钥、恢复码或其他凭据。

## 工具与认证

- 使用 Gitee 官方 CLI；运行时发现实际命令路径并执行版本核验，不在模板中预置作者机器路径。
- 使用 `gitee auth status` 实时核验登录状态，不把浏览器登录状态等同于 CLI 登录。
- PAT 直接进入官方交互终端或宿主安全凭据通道；不得通过聊天、命令参数、remote URL 或普通文档传递。

## 管理边界

- GLOBAL 只记录跨项目账号身份、CLI 路径、登录核验和安全规则。
- 仓库地址、默认分支、基线提交、开发分支、数据库、部署与交付状态进入对应项目，不复制到 GLOBAL。
- CLI 登录成功只表示身份可用，不代表已授权推送、合并、部署或生产变更。
