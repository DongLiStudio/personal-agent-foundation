# 阿里云 CLI / 云效身份对应关系

本文件记录用户决定由 GLOBAL 统一维护的阿里云账号与云效组织非敏感路由。只记录逻辑 Profile、主体、认证类型、组织/接入点、用途和验证方式；不得记录 AccessKey、Secret、STS、PAT、OAuth/SSO 票据、恢复码或凭据文件内容。

## 使用规则

- 身份新增、授权、恢复、迁移、切换和删除统一使用全局 `aliyun-profile` Skill。
- 阿里云通用 OpenAPI Profile 与云效 PAT 上下文是两套认证体系；逻辑名称可以统一，但不得互相替代。
- 操作前按“用户明确主体 → 项目规则 → GLOBAL 默认”解析唯一身份，并实时回读；CLI 当前激活项和残留环境变量都不是业务路由依据。
- 本文件登记身份不扩大权限。项目仓库、命名空间、流水线、环境和发布规则保留在对应项目。
- 删除 Profile、撤销 PAT、改变默认身份或安装系统软件会影响后续工作，执行前必须说明影响并取得明确授权。
