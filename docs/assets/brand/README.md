# Personal Agent Foundation 图标

连接节点代表 Agent、项目与工具，三层承托结构代表可持续复用的公共基座。标志不含字母或细小纹理，以保持小尺寸辨识度。

| 文件 | 用途 |
| --- | --- |
| logo.svg | 透明背景彩色主标，浅色背景 |
| logo-dark.svg | 透明背景深色背景版 |
| logo-mono.svg | 单色矢量版，通过 currentColor 继承颜色 |
| icon.svg / icon-512.png | 深蓝底圆角图标，适合头像与应用入口 |
| logo-32.png 至 logo-1024.png | 六种尺寸透明 PNG |
| preview.png | 浅色、深色及头像使用预览，包含 32px 检查 |

主色 #244C74，强调色 #16A6A0；深色背景 #102C46，深色版使用 #DDECF6 与 #46D5C1。图形四周保留至少画布宽度的 8% 空白，不拉伸、不增加阴影或改变节点比例。

矢量稿为可编辑源文件；PNG 由 SVG 渲染导出。图标按仓库 [Apache 2.0 许可证](../../../LICENSE)提供，不代表注册商标声明。
